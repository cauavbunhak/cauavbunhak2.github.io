O projeto se resume a um petshop, destinado exclusivamente a gatos, contendo produtos e serviços disponíveis para a compra.

Página Inicial: Disponibiliza um menu de navegação para o usuário, junto com um cadastro de agendamento de serviço, onde é possível preencher os dados do cliente e do seu animal.
Página de Produtos: Página destinada à apresentação de todas as categorias de produtos e várias opções dentro de cada categoria e com seus respectivos preços.
Página de Serviços: Página voltada somente para a navegação entre os serviços disponibilizados pelo petshop, contendo botão de agendar o serviço que direciona o cliente até o cadastro de agendamento.
Rodapé Unificado: Apresenta os direitos autorais do projeto, contendo também telefone e e-mail, além do endereço e das redes sociais do petshop.

As atualizações trouxeram mais interatividade com o site, um carregamento otimizado e um visual mais trabalhado se comparado à primeira versão, tornando o site mais dinâmico e agradável para o olhar do cliente.
O uso do Bootstrap local evita que o site demore a carregar e elimina possíveis erros visíveis.
